# Ghost Data Still Exists — Deletion Audit Agent

This repository contains the runnable evidence-driven solution and generated HackerRank deliverables. The source challenge data is fetched from the public upstream repository during the GitHub Actions run and is not committed here.

See `code/README.md` for the agent design and run instructions. The workflow writes `output.csv`, produces evaluation and usage reports, and publishes `code.zip` as a workflow artifact.
